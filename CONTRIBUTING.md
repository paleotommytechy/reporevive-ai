# Contributing to RepoRevive AI

Thanks for helping revive more open-source projects.

1. Open an issue describing the problem or proposed improvement.
2. Fork the project, create a short topic branch, and keep the change focused.
3. Run `python -m unittest discover -s tests -v` in `backend` and `npm run build` in `frontend`.
4. Describe what you changed, how you tested it, and include screenshots for UI work.
5. Do not send tokens, credentials, private repository data, or sensitive source files in issues.

**Good first issues**: improve loading-state accessibility, add detection for alternate testing conventions, document Windows setup, add a tutorial for running Ollama.

RepoRevive does not run scanned code. Please preserve that boundary in new features.
